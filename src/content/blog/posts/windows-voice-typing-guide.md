Windows has built-in voice typing that many people never discover. Here's how to use it, plus how it compares with Mac dictation if you use both.

## Start voice typing

1. Click into any text field.
2. Press **Windows key + H**.
3. Talk. Press Win + H again or click the microphone to stop.

## Turn on automatic punctuation

Automatic punctuation is **off by default**, so you'd otherwise say every comma.

1. Press **Win + H** to open the toolbar.
2. Click the **gear** icon.
3. Turn on **Automatic punctuation**.

Other options there include a voice typing launcher and microphone sound.

## Voice typing vs Voice Access

| | Voice typing (Win + H) | Voice Access |
|---|---|---|
| Purpose | Dictate text | Control the PC by voice and dictate |
| Processing | Microsoft online speech service | On-device |
| Availability | Windows 10 and 11 | Windows 11 (22H2 and later) |
| Auto-punctuation setting | Toolbar → gear | Voice Access bar → Settings → Manage options |

Voice Access is Windows' equivalent of macOS Voice Control ([Mac version](/blog/voice-control-vs-dictation-mac)).

## Useful voice commands

Windows voice typing understands punctuation names ("comma", "period", "question mark", "new line") and simple editing commands such as deleting what you just said or stopping dictation; the exact list depends on your language and Windows version, so check Microsoft's voice typing help for the current set. If automatic punctuation is on, you'll rarely need to say commas and periods.

## Privacy

Because Win + H voice typing uses an online speech service, your audio is sent to Microsoft for recognition. Windows' privacy settings for speech control this. For on-device recognition on Windows 11, use Voice Access. The same trade-offs apply on any platform: see [on-device vs cloud speech recognition](/blog/on-device-vs-cloud-speech-recognition).

## Tips

- Check your **default microphone** in Sound settings if nothing happens.
- Use **punctuation commands** when auto-punctuation guesses wrong.
- Same accuracy habits apply on every platform ([12 tips](/blog/speech-to-text-accuracy-tips)).

## Windows vs Mac at a glance

| | Windows | Mac |
|---|---|---|
| Quick dictation | Win + H | Microphone key / Dictation shortcut |
| Full voice control | Voice Access | Voice Control |
| On-device dictation | Voice Access | Apple Dictation (many languages) |
| Third-party apps | Many, often cloud | Many; on-device options like [MacVoice](/) |
