These are the commands Apple lists for Dictation on macOS. Bookmark this page, or keep it open while you practise. Commands are for English; other languages have their own.

> Using [MacVoice](/) instead? Its commands are a little different (including "bullet point" and "scratch that"). See the [MacVoice voice commands cheat sheet](/blog/mac-voice-typing-commands).

## Punctuation

| Say | You get |
|---|---|
| comma | , |
| period / point / dot / full stop | . |
| question mark | ? |
| exclamation mark | ! |
| colon | : |
| semicolon | ; |
| apostrophe | ’ |
| hyphen | - |
| dash | – |
| ellipsis | … |
| quote … end quote | “ ” |
| begin single quote … end single quote | ‘ ’ |
| open parenthesis / close parenthesis | ( ) |
| open square bracket / close square bracket | [ ] |
| open brace / close brace | { } |
| open angle bracket / close angle bracket | < > |

## Layout and spacing

| Say | What happens |
|---|---|
| new line | Starts a new line |
| new paragraph | Starts a new paragraph |
| tab key | Moves to the next tab stop |
| no space on / no space off | Types the next phrase without spaces / back to normal |
| numeral | Formats the next phrase as a number |
| roman numeral | Formats the next phrase as a Roman numeral |

## Capital letters

| Say | What happens |
|---|---|
| caps on / caps off | Next phrase in Title Case / back to normal |
| all caps | Next word in CAPITALS |
| all caps on / all caps off | Next phrase in CAPITALS / back to normal |

## Maths and money

| Say | You get |
|---|---|
| equal sign / plus sign / minus sign | = + - |
| multiplication sign | x |
| greater than sign / less than sign | > < |
| dollar sign / cent sign | $ ¢ |
| pound sterling sign / euro sign / yen sign | £ € ¥ |

## Emoticons and emoji

Say "smiley face" for :-), "frowny face" for :-(, or "winky face" for ;-). In supported languages you can insert real emoji by saying the name plus "emoji": "heart emoji", "thumbs up emoji".

## Tips

- **Pause briefly** before and after a command so it isn't mistaken for a normal word.
- **Auto-punctuation** adds most commas and periods for you; use the commands when you want to be exact. ([How auto-punctuation works](/blog/mac-dictation-auto-punctuation).)
- If **Voice Control** is on, it has its own, larger set of editing commands. See [Voice Control vs Dictation](/blog/voice-control-vs-dictation-mac).

Source: Apple's "Commands for dictating text on Mac" (Mac User Guide), checked November 2026.
