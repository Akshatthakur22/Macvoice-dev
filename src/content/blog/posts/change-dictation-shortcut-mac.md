A good dictation shortcut is one you can press without looking, that no other app uses. Here's how to set it.

## Change the Apple Dictation shortcut

1. Open **System Settings → Keyboard**.
2. Scroll to **Dictation** (it must be on).
3. Click the **Shortcut** pop-up menu.
4. Choose one of the presets, or choose **Customize** and press the key combination you want, for example **Option-Z**.

Some presets change related keyboard settings. For example, choosing to press the **Fn (Globe) key twice** can change what a single Fn press does. macOS updates the "Press 🌐 key to" option for you.

## Use the Microphone key

Newer Mac keyboards have a **Microphone key** (F5). A short press starts Dictation; pressing and holding it starts Siri. If you use an external keyboard without that key, a custom shortcut is the way to go.

## Picking a good shortcut

- **Use at least one modifier key** (Control, Option or Command) so you don't trigger it while typing.
- **Avoid common app shortcuts.** Command-Shift-S (Save As, and Google Docs voice typing), Command-Space (Spotlight) and Control-Space (input source switching) are taken.
- **Make it one-handed** if you'll often hold a coffee or a mouse with the other hand.

## If the shortcut doesn't respond

1. Test **Edit → Start Dictation** in the menu bar. If that works, the shortcut is the problem.
2. Pick a different combination. Another app (a launcher, screenshot tool or window manager) may be grabbing the keys first.
3. Check that Dictation is still on; turning it off removes the shortcut.

Still not working? See [Mac dictation not working: 10 fixes](/blog/mac-dictation-not-working).

## MacVoice's shortcut

[MacVoice](/) uses **Control + Option + Space** by default, which rarely clashes with anything. To change it: menu bar icon → **MacVoice Settings…** → **Shortcut** tab → click the shortcut button → press your new combination (it must include Control, Option or Command). If the keys are already taken, MacVoice keeps your old shortcut and tells you. Press the same shortcut once to start and again to stop.
